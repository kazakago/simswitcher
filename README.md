# SIM Switcher

SIM Switcher is a screenless, lightweight Android shortcut tool designed to launch the dual SIM (mobile network) settings screen directly from the Quick Settings panel.

## Features

- **Direct Shortcut**: Open the dual SIM settings screen with a single tap from your Quick Settings panel.
- **Active SIM Status Display**: Displays the current active data SIM carrier name directly in the tile's subtitle (requires Phone state permission).
- **Lightweight Design**: Built purely with native Android APIs, featuring zero external UI runtime dependencies (no Jetpack Compose or heavy UI libraries).
